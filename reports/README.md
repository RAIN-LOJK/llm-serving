# 报告

最终报告按 [ROADMAP.md](../ROADMAP.md) §7 的六节组织：

1. 问题与口径（为什么两代载体、为什么先纯后混）
2. 数值对拍（可信度地基）
3. 连续批与分页 KV 在纯注意力下的收益边界
4. **负结果专章**：哪些优化在这个规模下无效、为什么
5. 混合注意力：P1–P3 判定 + 显存交叉点 + 对调度/缓存的含义
6. 复现说明（一条命令一档）

约定：

- 每个数字引用 run id；跨设备/跨 dtype 不放进同一列。
- 目标值与实测值分列；W1 之前的阈值标 `target`。
- 负结果与正结果同等篇幅；“什么时候不划算”必须写。
- 图表从 `summary.json` 生成，不手工改数；图源脚本放 `reports/` 或 `bench/`。
